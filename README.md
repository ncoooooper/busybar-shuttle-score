# Shuttle Score

Keep badminton rally score, the serving side and deuce rules without tapping a phone.

Turn to select the side that won the rally and click to award its point. The winner serves from the right court at even scores and the left at odd. A game ends at 21 with a two-point lead, or at 30. Start undoes the last rally; hold Start clears the current game.

## Run locally

From this folder, run `~/.busy-emulator/bin/busy-emulator dev --once` with BUSY Bar Emulator open. Back exits.
